# security policy

## reporting a Vulnerability

I take the security of `kspman` seriously. If you discover a critical vulnerability (e.g., RCE, privilege escalation, or directory traversal), please report it responsibly so it can be address privately to ensure user safety.

Please **do not** report security vulnerabilities in public GitHub issues. Instead email me directly at the address provided on my GitHub.

## Disclosure Policy
When reporting a vulnerability, please provide:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Any other information

I will handle your report and manage a fix before any public disclosure, either on kspman's github page or a release note.
